KEEP-IT-SIMPLE

Password Manager

SYSTEM INFORMATION

DATE CREATED: FEBRUARY 2021

PROGRAMMING LANGUAGE USED: PHP, MySQL, JS

KEEP-IT-SIMPLE is a Password Manager website developed as the final requirement for our programming class This password manager is designed to securely store the login credentials of various user accounts. It is useful for individuals who have numerous accounts and need an efficient way to manage and remember their passwords when accessing their accounts.
